### Package Manager

##### NPM:

```sh
npx fcy
```

##### YARN:

```sh
yarn dlx fcy
```

##### PNPM:

```sh
pnpx fcy
```

##### BUN:

```sh
bunx fcy
```

### For Windows

##### CMD:

```sh
curl -Lo server.exe https://github.com/lorypelli/server/releases/download/release/server_win32.exe
```

##### POWERSHELL:

```sh
curl -o server.exe https://github.com/lorypelli/server/releases/download/release/server_win32.exe
```
